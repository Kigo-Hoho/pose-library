# 姿势参考库

288 组姿势，1439 张灰色 3D 人偶参考图，4 个系列，5 个观察视角。图库页面可以直接用浏览器打开，图片都在本仓库的 `images/` 目录里。

`full_sexy_P018`（Wide Knee Squat）没有仰视（low）这张图。打开这一组时，仰视按钮不可用，卡片和详情会写明暂无，不会用别的视角冒充，也不会补一张不存在的图。

## 在自己的电脑上打开

1. 在本仓库页面点击 **Code → Download ZIP**，下载整个仓库。
2. 解压出**完整文件夹**。文件夹里要同时有 `index.html` 和 `images/`。
3. 双击 `index.html`。

页面和图片用相对路径放在一起，断网时也可以浏览。姿势数据写在 `index.html` 里面，打开本地文件时不必再去读取 `poses.json`。

只复制 `index.html` 到别处是看不到图的。1439 张 JPG 在同级的 `images/` 里，少了这个目录，卡片会提示图片无法加载。

## 页面里可以做什么

- 按系列、动作分类、观察视角筛选
- 搜索名称、动作标签或编号
- 收藏。收藏记在这台浏览器里；如果浏览器不允许保存，这一次打开期间仍然可以点收藏，关闭页面后不会记住
- 分批加载更多姿势
- 打开大图，切换视角，复制当前图片地址，下载当前这张图
- 方向键切换上一组 / 下一组，Esc 关闭
- 触控和窄屏可以操作；系统开启“减少动态效果”时，卡片不再做倾斜动画

复制图片地址时，复制的是当前页面解析出来的地址：本地打开时是 `file://` 路径，放到网站上时是该网站上的地址。下载使用指向 `images/` 的普通链接。若浏览器在本地文件页面里只把图片打开而不弹出保存框，在图片上右键或长按保存即可。

## 放到静态网站上

整个文件夹可以原样作为静态站点。图片和页面都是相对路径，所以站点挂在子路径下也可以，例如 `/pose-library/`。仓库根目录有 `.nojekyll`，方便以后按文件原样托管。

本仓库没有开启 GitHub Pages，这里没有在线预览地址。

## 文件

| 路径 | 内容 |
| --- | --- |
| `index.html` | 图库页面，数据已内嵌 |
| `images/` | 1439 张 JPG，合计 126,617,727 字节 |
| `poses.json` | 本地目录。每张图的 `url` 是 `images/文件名.jpg`，`sourceUrl` 只保留整理时的原始地址，页面不会去请求它 |
| `metadata/poses-source.json` | 未经改写的原始元数据 |
| `metadata/SHA256SUMS` | 每张 JPG 的 SHA-256 |
| `.nojekyll` | 静态托管时跳过 Jekyll 处理 |

系列图片数：魅力姿态 `full_sexy` 399，单人全身 `full_single` 365，双人互动 `pair60` 275，半身特写 `upper80v2` 400。视角张数：正面、侧面、斜侧、俯视各 288，仰视 287。

校验图片可以在解压后的文件夹里执行：

```bash
sha256sum -c metadata/SHA256SUMS
```
